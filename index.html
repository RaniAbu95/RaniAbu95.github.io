Captain Fix

          

            An AI QA engineer: give it a URL, and it crawls the site, writes a test plan, generates Selenium tests, runs them and emails you the results.
            מהנדס QA מבוסס AI: נותנים לו כתובת אתר, והוא סורק אותו, כותב תוכנית בדיקות, מייצר בדיקות Selenium, מריץ אותן ושולח את התוצאות במייל.
          

          
    
            
  • Planner: Claude analyzes the page HTML and linked forms and produces a structured test plan (suites, steps, expected results, priority, negative cases) validated with Pydantic.Planner: ‏Claude מנתח את ה-HTML של האתר ושל הטפסים המקושרים ומפיק תוכנית בדיקות מובנית (סוויטות, צעדים, תוצאה צפויה, עדיפות, בדיקות שליליות) שמאומתת עם Pydantic.
    • 
            
  • Executor: turns each case into runnable Selenium code, self-repairs syntax errors with the LLM, and runs cross-browser (Chrome, Firefox, Safari).Executor: ממיר כל מקרה בדיקה לקוד Selenium, מתקן שגיאות תחביר בעזרת ה-LLM, ומריץ על כמה דפדפנים (Chrome, Firefox, Safari).
    • 
            
  • Failures can be filed straight to Jira or Trello with screenshots attached; results emailed via Brevo.כשלונות נפתחים אוטומטית כבאגים ב-Jira או ב-Trello עם צילומי מסך; התוצאות נשלחות במייל דרך Brevo.
    • 
            
  • Flask web app with user accounts, async job queue and PostgreSQL, containerized with Docker and deployed on Render.אפליקציית Flask עם משתמשים, הרצה אסינכרונית ו-PostgreSQL, ארוזה ב-Docker ומפורסמת ב-Render.
